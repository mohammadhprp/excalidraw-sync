Set up Excalidraw Sync

Connect your GitHub account, choose a repository, and verify the connection. The token is stored by the extension only, in chrome.storage.local, and is never sent to the Excalidraw page or read back into the sync panel.

    1. Connect

    Paste a GitHub fine-grained personal access token (PAT).

    How do I create a token?
    1. Open GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
    2. Under Repository access, choose Only select repositories and pick the repository you want to sync (or all repositories).
    3. Under Permissions → Repository permissions, set Contents: Read and write.
    4. Set an expiration, generate the token, then copy it here.

    Create a fine-grained token on GitHub

    2. Repository

    Pick a repository the token can access, or enter owner and name by hand, then confirm the sync details.

    3. Verify

    Test the connection to confirm the token can reach the repository.

    (repository not set) @ main
